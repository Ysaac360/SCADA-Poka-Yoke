# Poka-Yoke Vision Demo (Versão Gratuita)

Esta é a versão de demonstração de acesso gratuito do sistema Poka-Yoke com Visão Computacional. 
A finalidade deste repositório/pasta é apresentar as capacidades do nosso software de leitura de múltiplos códigos (QR, Barcode, Matrix) aliado à inteligência artificial (YOLO) rodando em tempo real.

## Uso
Você é livre para baixar, testar e analisar esta versão demo em seus ambientes locais e educacionais. 

Esta versão é ideal para:
- Validação técnica da solução de visão computacional.
- Testes de velocidade, FPS e leituras simultâneas.
- Conhecer a interface do Supervisório.

## Limitações
Por ser uma Demo, este software não inclui suporte técnico direto nem atualizações constantes. Para obter a versão completa preparada para automação industrial, comunicação robusta de dados via CLPs, rastreabilidade avançada e licenciamento comercial, conheça o **QR Industrial Reader**.
